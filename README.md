One-line apology from an office printer, entered in
[The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153)
on [make.fun](https://make.fun).

`main.py` writes the apology — a single line of at most 120 characters —
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## The line

> Sorry I keep jamming. It's the only hug I get all year — the rest of the time you just kick me and swear.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
